# make-knowledge-cards

把一篇文章（直接粘贴的文本，或本地 Markdown/TXT 文件）浓缩成 **5～8 张结构化知识卡片**，用于复习和自测。

## 目录结构

```text
First_Skill/
├── README.md
├── LICENSE                   # MIT 许可证
└── make-knowledge-cards/
    ├── SKILL.md              # Skill 主体：工作流程、卡片模板与示例
    └── agents/openai.yaml    # OpenAI/Codex 适配元数据（其他平台自动忽略）
```

## 1. 项目解决什么问题

读完一篇文章后，人们常常面临三个问题：重点太多记不住、笔记与原文一样长无法快速复习、想自测却没有题目。

`make-knowledge-cards` 把整篇文章压缩成一卡组**可复习、可自测**的卡片：只保留真正重要的知识，一卡一个知识点，并严格忠于原文——不凑数、不编造。

## 2. 主要功能

- 接受两类输入：直接粘贴的文章文本；本地 Markdown（.md/.markdown）和纯文本（.txt）文件
- 输出 5～8 张知识卡片，每张包含四部分：
  - **标题**：直接点出知识点
  - **核心知识**：一句话关键结论
  - **简明解释**：2～4 句讲清含义、原理或适用条件
  - **例子/自测**：优先使用原文例子，否则给出可由原文回答的自测题及答案
- 自动合并重复表述，卡片之间不重叠
- 原文的关键数字、阈值、年代、比例原样保留
- 原文独立知识点不足 5 个时，有多少做多少，并说明数量不足的原因

**不支持**：网页/URL 抓取、PDF 等非文本文件、Anki 牌组生成、图形界面。

## 3. 安装方法

本 Skill 是纯 Markdown 指令，**无需构建、不依赖运行时库**，安装即复制文件夹。

1. 下载或复制 `make-knowledge-cards` 整个文件夹。
2. 放入你所用 Agent 的技能目录，例如：
   - OpenAI Codex CLI：用户级 `%USERPROFILE%\.codex\skills\`（Windows）或 `~/.codex/skills/`（macOS/Linux）；项目级 `<项目>\.agents\skills\`
   - Claude Code：`~/.claude/skills/` 或项目内 `.claude/skills/`
   - 其他支持 Agent Skills 开放标准（SKILL.md 文件夹约定）的工具，按其文档放置
3. 如工具未自动发现新技能，重启或重新加载该工具。

可选：若要运行官方校验脚本 `quick_validate.py`，需要 Python 3 并安装 PyYAML：

```bash
pip install pyyaml
```

## 4. 使用方法

加载 Skill 后，用自然语言提出需求即可：

- 粘贴文章：`把下面这篇文章做成知识卡片：……`
- 读取本地文件：`把 notes/黑洞.md 转换成知识卡片`
- 需要保存为文件时补充：`并保存为 md 文件`（默认命名为 `<主题>-知识卡片.md`）

遇到不支持的输入（如 PDF、网址），Skill 会明确告知并停止，不会尝试绕过。

## 5. 输入输出示例

**输入**（直接粘贴的文本）：

> 复利是指投资收益会计入本金，下一期按新的本金总额继续产生收益，也就是“利滚利”。时间越长，复利带来的财富增长越显著。

**输出**：

```markdown
## 卡片 1：复利就是“利滚利”

- **核心知识**：复利是投资收益计入本金，下一期按新的本金总额继续产生收益，即“利滚利”。
- **简明解释**：与只按原始本金计息不同，复利每期的本金都在变大，上一期赚到的钱下一期也参与产生收益。
- **例子/自测**：自测：复利与只按本金计息有什么不同？（答案：复利的收益会加入本金，下一期一起产生收益。）

## 卡片 2：时间越长，复利增长越显著

- **核心知识**：复利带来的财富增长随时间拉长会变得格外显著。
- **简明解释**：本金像滚雪球一样逐期增大，复利效果主要靠时间积累，持有越久增长越可观。
- **例子/自测**：自测：让复利效果明显的关键条件是什么？（答案：足够长的时间。）

说明：原文只有 2 个独立知识点，因此输出 2 张卡片，未凑足 5 张。
```
