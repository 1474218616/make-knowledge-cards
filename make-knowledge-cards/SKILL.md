# Make Knowledge Cards

把一篇文章浓缩成一卡组可复习的知识卡片：只保留真正重要的知识，一卡一个知识点，不重复、不编造。

## 功能边界

支持的输入：

- 用户直接粘贴的文章文本
- 本地 Markdown 文件（.md、.markdown）和纯文本文件（.txt）

不支持（收到此类请求时明确告知并停止，不要尝试绕过）：

- 网页或 URL 抓取
- PDF、Word、图片、电子书等非 .md/.txt 文件
- 生成 Anki 牌组（.apkg）或导入 Anki
- 任何图形界面操作

## 工作流程

### 1. 获取输入

- 文本已粘贴：直接进入步骤 2。
- 用户给了本地文件路径：
  - 先确认扩展名属于 .md/.markdown/.txt；否则告知该类型不支持。
  - 读取文件全文。路径不存在或读取失败时如实报告，不要猜测或编造文件内容。
- 文本过短、没有实质知识点（如一句话、纯寒暄）时，说明情况并停止，不要硬造卡片。

### 2. 通读并提取知识点

- 通读全文，列出候选知识点：概念、原理、规则、方法与步骤、关键结论、易混点、注意事项。
- 按以下优先级判断重要性：
  1. 文章反复强调、重点论证或详细展开的内容
  2. 理解全文必须先掌握的核心概念和原理
  3. 可直接照做的方法、规则、流程
  4. 原文明确给出的对比、例子、适用条件与禁忌
- 合并同一知识点的不同表述；背景铺垫、修辞、重复举例不单独成卡。
- 按以下标准判定“一个知识点”：
  - 一套完整的操作步骤或流程算一个知识点，放在同一张卡片中分点列出，不要每一步各做一张；步骤之外独立的规则、技巧、注意事项才单独成卡。
  - 同一结论的正反两面（如“温和通胀可取、高通胀有害”）算一个知识点。
  - 同一主题下并列的分类或方法（如两种通胀成因、两种观测途径）合并为一张卡片，卡内分点。
- 原文中的关键数字、阈值、年代、比例（如“2% 左右”“超过太阳的 20 倍”）必须原样保留在对应卡片中，不得改写、四舍五入或遗漏。
- 候选知识点的每条信息都必须能在原文中找到依据，严禁加入原文没有的事实、数字、结论和例子。

### 3. 选定卡片

- 目标 5～8 张，按重要性从高到低选取。
- 一张卡片只讲一个知识点；卡片之间不重叠、不包含。
- 原文独立知识点不足 5 个时，有多少做多少，并在全部卡片之后用一句话说明数量少于 5 的原因；绝不为凑数拆分知识点或编造内容。
- 候选超过 8 个时，只保留最重要的 8 个；可在结尾一句话提及被省略内容的方向。

### 4. 逐张生成卡片

卡片语言与原文保持一致。严格使用以下 Markdown 模板：

```markdown
## 卡片 N：<标题>

- **核心知识**：<用一句话陈述该知识点的关键结论，必须能在原文中找到依据>
- **简明解释**：<2～4 句，用自己的话讲清含义、原理或适用条件；不整句照抄，不添加原文没有的信息>
- **例子/自测**：<优先复述原文中的例子；原文没有例子时，给出一道可由原文直接回答的自测题，并附简短答案>
```

标题要求：直接点出知识点，不超过 20 字，不使用空洞标题（如“基本概念”）。

### 5. 自检后交付

逐张核对，全部通过再输出：

- [ ] 每张卡片四要素（标题、核心知识、简明解释、例子/自测）齐全
- [ ] 每张卡片只讲一个知识点，卡片之间无重复、无重叠
- [ ] 核心知识与解释中的每条信息都能在原文中找到依据，无编造、无引申
- [ ] 数量为 5～8 张；不足 5 张时已说明原因
- [ ] 例子取自原文，或自测题答案可由原文直接推出

交付方式：

- 默认在对话中直接输出全部卡片的 Markdown，卡片前可加一行文章主题。
- 用户要求保存时，写入一个 .md 文件（建议命名为 `<原文件名或文章主题>-知识卡片.md`），并告知完整路径。

## 完整示例

输入文章：

> 光合作用是绿色植物利用光能，把二氧化碳和水转化为有机物并释放氧气的过程。它分为光反应和暗反应两个阶段：光反应在类囊体膜上进行，产生 ATP 和 NADPH；暗反应在叶绿体基质中进行，利用光反应的产物将二氧化碳固定为糖类。光反应必须有光，暗反应不直接需要光，但依赖光反应提供的能量和还原剂。

输出：

## 卡片 1：光合作用是什么

- **核心知识**：光合作用是绿色植物利用光能，把二氧化碳和水转化为有机物、并释放氧气的过程。
- **简明解释**：光合作用的原料是二氧化碳和水，产物是有机物和氧气，驱动能量来自光。它实现了光能向有机物中化学能的转化。
- **例子/自测**：自测：光合作用的原料和产物分别是什么？（答案：原料是二氧化碳和水；产物是有机物和氧气。）

## 卡片 2：光合作用的两个阶段与场所

- **核心知识**：光合作用分光反应和暗反应两个阶段，光反应在类囊体膜上进行，暗反应在叶绿体基质中进行。
- **简明解释**：两个阶段地点不同、分工不同：光反应产生 ATP 和 NADPH，暗反应利用这些产物把二氧化碳固定成糖类，前后衔接。
- **例子/自测**：自测：暗反应发生在叶绿体的什么部位？（答案：叶绿体基质。）

## 卡片 3：两个阶段对光的依赖不同

- **核心知识**：光反应必须有光才能进行；暗反应不直接需要光，但依赖光反应提供的能量和还原剂。
- **简明解释**：暗反应本身不直接消耗光，却离不开光反应的产物 ATP 和 NADPH，因此没有光，暗反应也会因产物耗尽而停止。
- **例子/自测**：自测：暗反应是否完全不需要光？为什么？（答案：不是；它不直接需要光，但依赖光反应提供的 ATP 和 NADPH。）

说明：原文只包含 3 个独立知识点，因此输出 3 张卡片，未凑足 5 张。
